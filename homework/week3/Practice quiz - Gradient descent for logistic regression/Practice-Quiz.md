# 练习测验：逻辑回归的梯度下降

## 1.（1 分）

**逻辑回归的梯度下降**

```
repeat {
    w_j = w_j - α [ 1/m Σ_{i=1}^{m} ( f_w,b(x^(i)) - y^(i) ) x_j^(i) ]
    b   = b   - α [ 1/m Σ_{i=1}^{m} ( f_w,b(x^(i)) - y^(i) ) ]
} simultaneous updates
```

$$f_{\vec{w},b}(\vec{x}) = \frac{1}{1 + e^{-(\vec{w}\cdot\vec{x}+b)}}$$

对于以下内容，哪一个是正确的更新步骤？

- [x] 更新步骤看起来与线性回归的更新步骤相似，但 $f_{\vec{w},b}(\mathbf{x}^{(i)})$ 的定义不同。
- [ ] 更新步骤与线性回归的更新步骤完全相同。

  ✔ 正确：对于逻辑回归，$f_{\vec{w},b}(\mathbf{x}^{(i)})$ 是 sigmoid 函数，而不是一条直线。
