# 吴恩达机器学习课程学习笔记与作业实践

## 项目简介
本文件夹为吴恩达机器学习（Andrew Ng's Machine Learning）课程的学习仓库，涵盖了课程笔记、课后作业实现，以及数据科学核心组件（NumPy、Pandas、Matplotlib）的专项练习与 Jupyter 交互式笔记。

## 目录结构与功能说明
- **`.git`**：Git 版本控制目录，用于追踪代码与笔记的迭代历史。
- **`.ipynb_checkpoints`**：Jupyter Notebook 的自动保存检查点目录。
- **`.venv`**：Python 虚拟环境目录，隔离本项目依赖，避免与全局环境冲突。
- **`homework`**：课程官方课后作业及个人实现代码，包含模型训练与评估。
- **`jupyter`**：Jupyter Notebook 相关配置及基础操作笔记。
- **`notebook`**：课程核心知识点的交互式学习笔记（含代码运行记录）。
- **`numpy`**：NumPy（数值计算基础库）的专项学习笔记与练习。
- **`pandas`**：Pandas（数据处理与分析库）的专项学习笔记与练习。
- **`matplotlib`**：Matplotlib（数据可视化库）的专项学习笔记与绘图练习。
