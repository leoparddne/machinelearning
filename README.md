# 吴恩达机器学习课程（中文翻译与练习）

## 项目简介
本仓库为吴恩达机器学习（Andrew Ng's Machine Learning）课程的学习记录，涵盖课程的中文翻译、课程笔记、数据科学核心组件（NumPy、Pandas、Matplotlib）的专项练习，以及课后作业。

## 目录结构与功能说明
- **`.git`**：Git 版本控制目录，用于追踪代码与笔记的迭代历史。
- **`.ipynb_checkpoints`**：Jupyter Notebook 的自动保存检查点目录。
- **`.venv`**：Python 虚拟环境目录，隔离本项目依赖，避免与全局环境冲突。
- **`0. notebook`**：机器学习核心知识点的个人学习笔记。
- **`1. jupyter`**：Jupyter Notebook 相关配置及基础操作笔记。
- **`2. numpy`**：NumPy（数值计算基础库）的专项学习笔记与练习。
- **`3. matplotlib`**：Matplotlib（数据可视化库）的专项学习笔记与绘图练习。
- **`4. pandas`**：Pandas（数据处理与分析库）的专项学习笔记与练习。
- **`homework`**：课程作业区，详见下方说明。

## 关于 homework 文件夹
`homework` 最初只用于存放我个人的课程作业。在学习过程中，发现直接阅读原版英文文档比较吃力，因此本仓库同时承担了**翻译**的作用——将课程中的文档、图片、Lab 与测验等内容翻译为中文。

该文件夹包含两部分内容：
- **原版课程内容**：课程官方提供的文档、图片、数据文件，以及所有 Lab 与测验（已翻译为中文）。
- **个人练习内容**：在完成原版 Lab 后，根据个人理解重新实现与扩展的练习。

希望这份中文翻译能为同样在学习该课程的人提供帮助。
